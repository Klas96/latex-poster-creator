# Poster Templates

This directory contains templates for generating posters.

## Layered Structure

For LaTeX posters, a layered approach is used, with templates organized into the following subdirectories:

- `background/`: Templates for the background layer (e.g., base colors, textures).
- `midground/`: Templates for the midground layer (e.g., secondary visuals, connecting elements).
- `foreground/`: Templates for the foreground layer (e.g., main text, primary figures).

Each subdirectory or file within this directory might represent a distinct poster design or layout.

The API endpoint `/poster/{template_name}` can be used to access or utilize these templates, potentially by combining elements from these layers.
